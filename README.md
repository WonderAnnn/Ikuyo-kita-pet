# Ikuyo Pet

Ikuyo Pet 是一个面向 Windows 的离线健康提醒与有效工作时间记录工具。它默认使用透明、可拖动桌宠提醒喝水和活动，也可以关闭桌宠，仅使用 Windows 原生通知。

## 当前阶段

仓库目前只有项目骨架和设计文档，尚未实现提醒、SQLite、工作计时或桌宠渲染。

- 设计规格：`docs/superpowers/specs/2026-09-06-ikuyo-pet-design.md`
- 实现计划：`docs/superpowers/plans/2026-09-06-ikuyo-pet-mvp.md`
- 开发工具目录：`G:\IkuyoPetDev`
- 源码目录：`F:\Health`

## 隐私边界

第一版离线运行，不保存医疗报告，不记录睡眠，不读取键盘内容、窗口标题、文档内容或屏幕截图。应用只统计用户白名单中的前台应用有效时间。

## 医疗说明

Ikuyo Pet 不是医疗器械，不提供诊断或治疗建议。提醒规则应根据个人情况和医生意见调整。
