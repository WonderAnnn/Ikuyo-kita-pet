# 默认皮肤资源目录

此目录是可再分发默认皮肤的占位目录。目前只提交元数据清单，不包含人物图片。正式默认皮肤必须是原创素材，或具有允许修改与再分发的明确授权。

最小资源集：

```text
manifest.json
idle.png
remind.png
```

`idle.png` 与 `remind.png` 应使用透明背景，建议画布为 512 × 512 像素。清单中的画布尺寸和帧率应与实际资源匹配，并通过 [`schemas/skin-manifest.schema.json`](../../../schemas/skin-manifest.schema.json) 校验。

## 版权边界

不要把以下内容提交到本仓库：

- “喜多郁代”或其他第三方商业动漫角色素材；
- 从动画、漫画、游戏、官方网站或他人作品中截取的图片；
- 许可不明、仅允许个人使用或禁止再分发的素材；
- 用户私有皮肤、AI 服务凭据或生成服务缓存。

用户可将有权使用的第三方皮肤保留在本机私有皮肤目录中；它们不受本项目 MIT 许可证覆盖。第二阶段计划提供应用内 AI 生成工作室，但生成结果仍需遵守所用模型、素材和角色相关权利。

## 清单字段

当前清单包含：

- `id`：稳定且唯一的皮肤标识；
- `name`、`version`、`author`、`license`：显示和授权信息；
- `canvasWidth`、`canvasHeight`：资源画布尺寸；
- `fps`：动画目标帧率，上限为 30。

加入正式资源时，请在此文件补充作者、来源、许可证链接和必要的署名方式。
