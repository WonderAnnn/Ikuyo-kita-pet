# UI 修整与工作时长口径设计

## 目标

修整筛选控件和主页面的视觉反馈，并让工作统计的时间范围、累计工作时长和版本信息对用户清晰可见。

## 已确认的交互

- 筛选控件采用 A 方案：白色底、细粉色焦点边框、浅粉色下拉选中项，不显示 Windows 默认浅蓝色按下背景。
- 左侧导航按钮取消系统虚线焦点框，但保留正常点击导航行为。
- 日志统计范围使用本地北京时间，并显示在总有效工作时长后：
  - 日：选定日期，例如“北京时间 2026年9月10日”；
  - 周：选定日期及其前 6 天，共 7 个自然日；
  - 月：选定日期及其前 29 天，共 30 个自然日。
- 主页面“有效工作”卡片拆成两层：大数字显示所有已记录有效工作累计，小字显示今天（北京时间）的有效工作。
- 设置页最底部显示应用版本号，本次版本递增为 `0.1.1`，以后每次发布修改同一版本源。

## 数据边界

累计工作只汇总已持久化的有效白名单前台工作会话，并叠加当前尚未结束的实时工作秒数；不包含后台、锁屏、睡眠或无操作时间。日志统计仍按所选滚动日期范围计算。

## 失败处理

- 旧仓储或测试仓储不支持全量工作会话查询时，主页面累计值回退为当前可用值，不影响提醒和日志页面。
- 版本号为编译期常量，缺失资源不会阻止启动。

## 验收标准

1. 点击日志筛选框时不再出现浅蓝色大块或系统默认按下态。
2. 点击左侧导航时不再出现矩形虚线焦点框。
3. 日/周/月统计后面显示明确的北京时间日期范围。
4. 主页面同时显示累计有效工作和今日有效工作。
5. 设置页底部显示 `版本 0.1.1`。
6. 现有统计、提醒、日志和皮肤测试全部通过。
