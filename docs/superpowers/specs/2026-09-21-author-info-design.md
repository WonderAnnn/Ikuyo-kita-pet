# 作者信息与 README 收口设计

## 目标

在不改变 Ikuyo Pet 现有功能、导航结构和素材内容的前提下，补充作者归属信息，并修复 README 中 Windows 通知回退截图展示不完整的问题。

## 方案

1. 在 README 增加“作者与项目”小节，明确作者为“成都信息工程大学 WonderAnn”。同时保留项目为非官方同人创作、与原作版权方无关联的说明。
2. 在设置页可滚动内容底部增加轻量作者信息，不新增导航项，不改变业务逻辑，不记录或上传任何个人数据。
3. 补全 README 的 Windows 通知回退 HTML 表格，使用仓库已有的 3 张通知截图；不删除、不替换现有截图。

- README 中能看到作者信息和完整的 3 张 Windows 通知截图。
