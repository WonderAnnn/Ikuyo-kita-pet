# 自适应手绘气泡主题设计

## 目标

把用户授权的三个原创透明 PNG 作为内置气泡主题，替换当前固定圆角矩形气泡。主题选择位于“桌宠与皮肤”页面，第一张为默认；提醒正文与操作链接在气泡内部完整显示，正文垂直居中、水平靠左，气泡尺寸随内容测量增长。

## 约束

- 原创 PNG 只在 `assets/bubbles/` 下跟踪；代码许可证与图片授权分开说明。
- 不把 AI 试验图作为默认运行时资源；后续 AI 延展只保留接口/实验说明。
- 不拉伸人物、乐器和涂鸦线条。每个主题记录内容安全区与九宫格切片边距，只拉伸中间干净区域。
- 气泡内部由主题渲染器提供整体白色填充；不再叠加第二个白色圆角气泡。
- 操作链接必须保持可点击，并位于装饰图层之上。
- 选择保存到本机，主题缺失时回退第一主题，不影响提醒调度。

## 结构

`IkuyoPet.Core` 定义不可变 `BubbleThemeDefinition`、`BubbleTextMetrics` 与 `BubbleLayoutCalculator`；`IkuyoPet.Infrastructure` 保存 `bubble-theme.json` 选择；`IkuyoPet.Pet` 提供 `BubbleChrome` WPF 控件和 `PetWindow.SetBubbleTheme`，使用九宫格绘制固定角/边与可扩展中段；`IkuyoPet.App` 加载内置目录、绑定卡片选择并把变更实时推送给桌宠窗口。

主题元数据至少包含：稳定 ID、显示名、版本、资源路径、预览路径、原图像素尺寸、`SliceInsets`、`TextSafeArea`、最小/最大内容宽高。主题 2 的安全区右移并给出更大的中段扩展空间，避免左侧人物与吉他压住文字。

## 交互与回退

启动时读取选择；空值、未知 ID、资源或元数据无效均使用主题 1。设置页卡片显示统一缩略图、名称、简短说明、选中边框和“默认”标记；点击卡片立即保存并更新已显示的气泡。图片加载失败时显示占位图并保留文本可读性。

## 验收标准

1. 三个 PNG 在 Git 中可追踪，预览卡片均能显示。
2. 短、中、长文本均不截断、不出气泡；正文垂直居中、靠左。
3. 主题 2 的文字区域位于人物/乐器右侧，长文本优先横向扩展中段。
4. 气泡内只有一层整体白底，没有白色圆角叠层或透明棋盘格。
5. 点击操作链接仍能触发原有 `ActionInvoked`。
6. 重启后选择保持；删除/损坏选择文件会安全回退主题 1。
