# 白名单进程诊断与计时测试实现计划

> **面向 AI 代理的工作者：** 使用 TDD 逐步实现，每一步先验证失败，再实现最小行为。

**目标：** 让用户明确填写“进程名/显示名”的含义，能够读取当前运行进程、快速填入白名单，并通过短时前台测试确认该进程是否满足有效工作计时条件。

**架构：** Core 提供纯函数诊断规则；Infrastructure 读取 Windows 当前运行进程、前台进程、锁屏与最近输入状态；App ViewModel 负责命令、状态和异步测试流程；SettingsView 用两列说明和运行进程选择器呈现结果。

**边界：** 不记录窗口标题、窗口内容、睡眠时间或医疗信息；测试只读取进程名、前台状态、锁屏状态和最近输入时间。
