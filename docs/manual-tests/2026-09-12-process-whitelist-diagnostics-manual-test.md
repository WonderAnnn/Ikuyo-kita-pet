# Ikuyo Pet 白名单进程诊断手工测试

版本：0.1.3+

## 目的

确认设置页能解释两个输入框的含义，读取当前运行进程，并用 5 秒测试判断目标应用是否满足正式有效工作计时条件。

## 启动与页面

1. 双击 `G:\testPet\artifacts\publish\win-x64\IkuyoPet.exe`。
2. 打开“设置”→“有效工作统计白名单”。
3. 确认看到两列输入框：
   - **进程名（用于匹配）**：填写 Windows 进程名，不含 `.exe`，例如 `WINWORD`、`pycharm64`；它决定是否计时。
   - **显示名（仅用于日志）**：填写日志展示名称，例如 `Microsoft Word`、`PyCharm`；它不参与匹配。

## 读取并核对运行进程

1. 先启动要统计的应用（例如 Microsoft Word、PyCharm 或 VS Code）。
2. 点击“刷新当前运行进程”。
3. 在“当前正在运行的进程”下拉列表中找到目标应用；列表格式为“进程名 (PID 数字)”。
4. 选中后点击“填入上方输入框”，确认进程名和显示名自动写入。
5. 如需加入白名单，点击“添加到白名单”，确认下方出现“已启用”条目。
6. 列表只读取进程名和 PID，不读取窗口标题、文件名、窗口内容或键鼠内容。

## 5 秒计时可用性测试

1. 确认目标进程已加入白名单，并把它切到前台。
2. 点击“测试计时（5 秒）”。
3. 在 5 秒内保持目标应用前台，并轻按键盘或移动鼠标。
4. 预期显示：`测试通过：... 正在前台、电脑未锁屏、不在全屏/演示模式且最近有操作，正式计时可以累计。`
5. 依次验证失败提示：
   - 目标应用只在后台运行：提示“后台运行不会计时”。
   - 切到桌面或未加入白名单应用：提示当前前台进程不匹配。
   - 锁屏：提示锁屏时间不会计时。
   - 全屏或演示模式：提示该状态下不会累计有效工作。
   - 5 秒内不操作且系统空闲超过 5 分钟：提示最近没有键盘或鼠标操作。

## 正式计时边界

正式统计继续使用同一组条件：白名单进程位于前台、电脑未锁屏、最近 5 分钟有人机操作，并且不在全屏/演示抑制状态。切屏、后台运行、锁屏、睡眠和长时间无操作均不累计；不记录睡眠时间。
