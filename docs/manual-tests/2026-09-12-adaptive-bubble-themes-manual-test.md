# 自适应气泡主题手工测试

## 准备

1. 使用 `win-x64` 发布应用，确认发布目录存在 `assets/bubbles`，且三个主题目录均包含 `bubble.png` 与 `manifest.json`。
2. 启动应用，打开“桌宠与皮肤”，确认“气泡样式”区域正好显示三张横向卡片，第一张“云朵晕乎”默认选中且图片保持原比例。

## 选择与持久化

1. 依次点击三张卡片，确认粉色选中边框只落在当前卡片，桌宠已显示的气泡立即切换，按钮周围不出现矩形虚线焦点框。
2. 选择第二张“吉他现场”后退出并重启，确认仍选中第二张；检查 `%LocalAppData%/IkuyoPet/bubble-theme/bubble-theme.json` 保存对应 ID。
3. 关闭应用，破坏选择 JSON 或写入未知 ID 后重启，确认安全回退第一主题且提醒调度仍可运行。

## 内容与操作

1. 对每个主题分别触发短文本、中等文本和中文长文本提醒，确认文字不截断、不越出气泡，正文垂直居中并左对齐。
2. 在第二主题检查人物与吉他位于文字左侧，正文安全区右移，长文本优先向横向扩展且不覆盖人物。
3. 检查气泡只有主题图片提供的一层整体白底，不出现叠加的白色圆角矩形或透明棋盘格。
4. 点击提醒中的所有操作链接，确认链接位于装饰层上方、可点击，并触发原有完成/稍后/跳过行为。

## 损坏资源回退

1. 在测试副本中删除当前主题的 `bubble.png` 后启动，确认选择回退到第一主题；若第一主题图片也不可用，文本仍应可读且应用不崩溃。
2. 恢复发布目录资源后重新启动，确认三张预览及实时切换恢复正常。
