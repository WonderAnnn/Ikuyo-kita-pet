# Ikuyo Pet A 版 PDF 导出手工测试

## 目的

验证日志页能在离线环境生成 A 版活泼主题 PDF，且导出内容只包含提醒日志和统计信息，不包含睡眠、医疗报告、窗口标题或窗口内容。

## 环境

- Windows 10/11
- .NET 10 Desktop Runtime
- Ikuyo Pet 版本 0.1.2 或更高
- 系统区域设置为北京时间（Asia/Shanghai）

## 测试步骤

1. 启动 Ikuyo Pet，进入“日志”页面。
2. 选择一个有提醒记录的日期，确认页面显示日期、类型和结果筛选。
3. 在工作统计区域依次选择“日”“周”“月”，确认总有效工作和北京时间范围正常。
4. 点击筛选栏右侧“导出 PDF”。
5. 在保存对话框中保留默认文件名 `IkuyoPet-日志-yyyyMMdd.pdf`，保存到临时目录。
6. 使用 Windows 浏览器或 PDF 阅读器打开文件。
7. 检查以下内容：
   - 页眉显示 Ikuyo Pet、粉珊瑚 A 版主题、拨片和五线谱装饰。
   - 统计卡片显示喝水完成、活动完成、有效工作。
   - 最多显示五个应用的前台时间横向柱状图。
   - 日志表格显示时间、类型、渠道、结果和备注。
   - 页脚显示“非官方元素”，并声明不记录睡眠、医疗报告或窗口内容。
8. 返回应用，设置类型或结果筛选后再次导出，确认 PDF 只包含当前筛选后的日志。
9. 在没有日志的日期重复导出，确认仍能打开 PDF，并显示“这一天还没有日志”。
10. 在保存对话框点击“取消”，确认应用不报错，状态提示显示“已取消 PDF 导出”。

## 通过标准

- 导出的文件扩展名为 `.pdf`，能够正常打开。
- PDF 页面无黑块、文字裁切、图表重叠或空白异常。
- 中文日期、中文日志和统计范围可读。
- 导出过程不联网，不要求 MySQL、SQLite 客户端或 Python 环境。
- 应用继续正常提醒、记录日志和统计有效工作。
